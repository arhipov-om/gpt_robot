# GPT Робот

Telegram-бот, который выступает в роли AI-ассистента с памятью разговоров.

## О проекте

Этот проект представляет собой чат-бота, разработанного на Python с использованием `aiogram` и `langchain`. Он подключается к Telegram-боту и использует языковую модель для ответа на сообщения пользователей. Бот запоминает контекст разговора, используя базу данных Redis для истории сообщений.

## Возможности

-   Интеграция с Telegram-ботом с использованием `aiogram`.
-   Интеграция с языковой моделью через `langchain`.
-   История разговоров хранится в Redis.
-   Легкая настройка и запуск с помощью Docker.
-   Отвечает на текстовые сообщения и команды.

## Конфигурация

Бот настраивается с помощью переменных окружения. Создайте файл `.env` в корне проекта, скопировав его из примера:

```bash
mv .env.example .env
```

Затем отредактируйте файл `.env`, указав свои учетные данные:

-   `DEBUG`: Установите `1` для отладочного логирования, `0` для информационного.
-   `BOT_TOKEN`: Ваш токен Telegram-бота.
-   `REDIS_URL`: URL для вашего экземпляра Redis (например, `redis://redis:6379/0`).
-   `LLM_API_KEY`: API-ключ для языковой модели.
-   `LLM_BASE_URL`: (Необязательно) Базовый URL для API языковой модели.
-   `LLM_MODEL`: Название используемой языковой модели.

## Начало работы

### Использование Docker (рекомендуется)

Это самый простой способ запустить бота.

**Предварительные условия:**
- Установлены Docker и Docker Compose.

**Шаги:**
1.  **Настройка:** Создайте и заполните файл `.env`, как описано в разделе "Конфигурация".
2.  **Сборка и запуск:**
    ```bash
    docker-compose up --build
    ```
    Эта команда соберет Docker-образ бота, запустит бота и контейнер Redis, а вы увидите логи бота в своем терминале.

### Локальная установка

Для запуска бота непосредственно на вашей машине.

**Предварительные условия:**
- Python 3.13+
- Установлен `uv` (`pip install uv`)
- Работающий экземпляр Redis.

**Шаги:**
1.  **Настройка:** Создайте и заполните файл `.env`, как описано в разделе "Конфигурация".
2.  **Установка зависимостей:**
    ```bash
    uv sync
    ```
3.  **Запуск бота:**
    ```bash
    python main.py
    ```

## Использование

После запуска бота вы можете взаимодействовать с ним в своем клиенте Telegram.

-   **/start:** Начать новый разговор. Это также можно использовать для очистки предыдущей истории разговоров.
-   **/help:** Получить информацию о боте и о том, как очистить историю разговоров.
-   **Начать разговор:** Отправьте любое текстовое сообщение боту. Он ответит и запомнит ваше сообщение.

Также доступна кнопка "Новый запрос" для очистки истории разговоров.
